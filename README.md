# Home-SOC-Lab
This project demonstrates the deployment of a Cloud-based Cyber Threat Capture System (Honeypot) on Microsoft Azure. By exposing an intentionally vulnerable Virtual Machine to the public Internet, the system entices real-world attackers. Failed authentication logs are collected, enriched with geographical data, and forwarded to an Azure Log Analytics Workspace. The data is then integrated into Microsoft Sentinel (SIEM) to visualize attacker locations in real-time on a Global Attack Map.
